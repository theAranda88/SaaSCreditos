# Skill: Backend → Frontend

## Cuándo

Swagger al día y tests API verdes.

## Buenas prácticas

- Permisos desde guards del API, no desde un Excel mental.
- Acción prohibida: no botón **y** 403 si se llama igual.
- Modelos en español (`Credito`, no `Credit`).
- Encadenar `calidad-tests` de la feature.
